# de la Peña Lab website

Source for delapenalab.com, the website of the de la Peña Lab at the University of New Mexico School of Medicine.

- `index.html`: the whole site (one page with hash routing: #research, #people, #publications, #funding, #news, #resources, #rnaclub).
- `img/`: photos, figures, and logos.

Hosted with GitHub Pages.
